# Mortgage brokers page review

Route: `/industries/mortgage-brokers`

## Direction

The page owns the long client relationship: an agreed check-in before readiness, relevant reconnection with an older enquiry, and broker approved review invitations after settlement. It extends the incumbent Zapla visual language without replacing the shared navigation or footer.

USE: actual Zapla identity, existing local fonts, portrait system and root navigation/footer.
ADAPT: the incumbent industry's restrained human context and short causal scenes for a relationship that unfolds over months rather than a workshop booking.
REJECT: replacing specialist mortgage software, generic AI advice, fabricated returns or testimonials, native integration promises, decorative dashboard chrome and looping customer state.

## Verification

- Production build and TypeScript check passed.
- Browser inspection at 320, 390, 768, 1024 and 1440 CSS pixels: no page overflow; hero cards do not intersect.
- Inspected full desktop/mobile pages and close hero crops; corrected narrow-screen card overlap.
- Reduced-motion and normal-motion browser runs: no page JavaScript or hydration errors after fixing the initial reduced-motion mismatch.
- Annual review/fixed rate toggle, keyboard FAQ, replay and pause passed. Prospect scene reaches final state then holds.
- Page images/fonts loaded. Existing shared footer social icons rely on externally hosted URLs unavailable to the local check; the shared footer was preserved.

## Evidence limits

These scores judge communication and implementation. They do not establish broker demand, conversion rate, acquisition economics, compliance approval or live workflow capability. No real mortgage-broker customer study or ROI data was supplied. The page deliberately makes no claim of guaranteed approvals, savings, native connections or automatic advice.

## October 9 photographic revision

The user approved the hero composition and asked for a newly generated, larger image, with supporting imagery following the latest Dental page review. The screenshot supplied in this chat was inspected directly. The current Dental source, review document and full-page render were inspected; conversation search was unavailable, so no claim is made that an unseen chat image was retrieved.

USE: the approved asymmetric hero composition and current Dental glass treatment.
ADAPT: Dental's varied photographic scale and compact overlays for property searches and client relationships.
REJECT: reusing the existing broker photographs, covering faces with large message panels, repeating the same split composition for the settlement scene, or embedding software UI into generated photos.

Three new original photographs were generated with the built-in image-generation tool and encoded to WebP:

Generation briefs: candid contemporary Australian broker and clients discussing property plans, portrait 4:5, natural cream/oak/sage office with clear foreground; clients viewing a light-filled Sydney home, landscape 3:2 with subjects right and space for a separate overlay; a settled client and partner talking at an oak table at home, wide 16:9 with subjects right and calm space left. All specified natural documentary photography, correct anatomy and no text, logo or UI. Original masters remain outside the repository.

At desktop width 1440 the hero photo grows from about 545 × 455 to 660 × 555 CSS pixels. Its cards retain their compact width. The glass matches Dental: warm white at 91% opacity, 2px white border, subtle inset edge, 6px background blur, restrained shadow and 18px corners. Supporting images lazy-load. The annual/fixed rate scene is now a broad photograph below a two-column heading rather than another alternating split panel. On mobile its overlays move into document flow so images, faces and text remain readable.

Revised full desktop/mobile pages and detailed hero/supporting crops were inspected. Five widths (320, 390, 768, 1024 and 1440) show no horizontal overflow and no hero/prospect card overlap. Page assets loaded, normal and reduced motion have no JavaScript/hydration errors, and tabs, keyboard FAQ, replay and pause passed. The production build and TypeScript check passed. The unchanged external shared-footer icon limitation remains.

The original conversion score assessed page communication only. It should not be read as a 9 for real conversion performance: measured broker conversion, return on setup cost and workflow operation remain unproven. This revision improves art direction, not that evidence.
