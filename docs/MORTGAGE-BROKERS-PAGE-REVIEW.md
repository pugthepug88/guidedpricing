# Mortgage brokers page review

Route: `/industries/mortgage-brokers`

## Direction

The page owns the long client relationship: an agreed check-in before readiness, relevant reconnection with an older enquiry, and broker approved review invitations after settlement. It extends the incumbent Zapla visual language without replacing the shared navigation or footer.

USE: actual Zapla identity, existing local fonts, portrait system and root navigation/footer.
ADAPT: the incumbent industry's restrained human context and short causal scenes for a relationship that unfolds over months rather than a workshop booking.
REJECT: replacing specialist mortgage software, generic AI advice, fabricated returns or testimonials, native integration promises, decorative dashboard chrome and looping customer state.

## Verification

- Production build and TypeScript check passed.
- Browser inspection at 320, 390, 768, 1024 and 1440 CSS pixels: no page overflow; hero cards do not intersect.
- Inspected full desktop/mobile pages and close hero crops; corrected narrow-screen card overlap.
- Reduced-motion and normal-motion browser runs: no page JavaScript or hydration errors after fixing the initial reduced-motion mismatch.
- Annual review/fixed rate toggle, keyboard FAQ, replay and pause passed. Prospect scene reaches final state then holds.
- Page images/fonts loaded. Existing shared footer social icons rely on externally hosted URLs unavailable to the local check; the shared footer was preserved.

## Evidence limits

These scores judge communication and implementation. They do not establish broker demand, conversion rate, acquisition economics, compliance approval or live workflow capability. No real mortgage-broker customer study or ROI data was supplied. The page deliberately makes no claim of guaranteed approvals, savings, native connections or automatic advice.
